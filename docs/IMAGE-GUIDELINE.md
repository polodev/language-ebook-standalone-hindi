# Illustration and visual design contract

Every chapter, including reviews/builders and vocabulary chapters, has two required reading illustrations. Author the text first, then its two prompts. This differs from pre-submitting a whole un-authored book: submit completed chapter batches while later chapters are being written, so images actually match the readings.

Each subject must describe the topic; story/article mode; precise scene or explanatory visual idea; setting; character/action; relevant objects; framing; lighting; and empty areas needed by layout. Derive these from scene_summary and the actual reading. Reading 1 and reading 2 must look meaningfully different. Use a consistent bright editorial illustration style or a coherent photographic style chosen in supplementary.json. Prefer uncluttered, warm, colourful adult-learning scenes, readable gestures and clear focal points. Avoid generic repeated stock images and cultural stereotypes. Bangladesh and destination-language settings should both feel plausible.

Include: "No readable text, no labels, no signage, no watermark." No letters, digits, words, brand logos or fake UI in generated artwork. Alphabet glyphs, number cards, pronunciation, title and captions must be drawn later using real embedded fonts. A script lesson never relies on an image model to draw the correct character. Strokes/diagrams should use verified vector geometry or font-based construction if needed.

Cover and banner are required global images. Cover: 1024x1536, upper third calm for title. Banner: 1536x1024, left third calm for real typography. Chapter art: 1536x1024. Both dimensions divide by 8. Project generation policy is gpt-image-2, low quality; a justified single-image medium override is allowed. Prompt writing does not mean a bitmap exists. Paid generation belongs to a separately requested production phase.

Source prompts: chapters/chNNN.json image_prompts and global-images.json. scripts/manage.py assemble produces generated/image-declaration.json for the bundled image pipeline. Canonical chapter files are assets/images/chNNN_bridge_reading_01.png and assets/images/chNNN_target_reading_01.png; cover assets/images/cover.png; banner assets/banner/art/banner.png. Actual paths come from assets/images.json. Keep generated-at, full composed prompt, model, size, quality and path there; preserve source and manifest in Git. Never fabricate these records.

Visual brief: prominent native script, smaller nearby Bangla pronunciation and meaning, generous spacing, strong hierarchy, 15 palette rotation every five items, balanced images and text. Keep three language lines on the same card. Mobile uses one complete card per row, never a squeezed desktop table. Arabic target blocks use RTL with isolation; Bangla and romanization stay LTR. Japanese/Chinese breaking must respect script punctuation; Hangul blocks and combining marks must remain intact. No fixed-height clipped lesson boxes. Covers, title pages and footers say Published by Englishing.app using real type.
