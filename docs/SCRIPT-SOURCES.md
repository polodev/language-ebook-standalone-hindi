# Writing-system engineering references

Used for the writing-system distinctions and shaping requirements, not as an official syllabus or source of lesson prose. Chapter-stage allocations are our editorial decisions. Future authors should consult authoritative target-language teaching references for actual lesson choices and record those sources in roster/review records.

- Unicode South/Central Asia (Devanagari): https://www.unicode.org/versions/Unicode17.0.0/core-spec/chapter-12/
- Unicode East Asia (Han, kana, Hangul): https://www.unicode.org/versions/Unicode17.0.0/core-spec/chapter-18/
- Unicode Middle East (Arabic and joining behaviour): https://www.unicode.org/versions/Unicode17.0.0/core-spec/chapter-9/

Keep native script separate from pronunciation metadata. Apply native text shaping and correct direction in layout; never reverse Arabic strings or substitute romanization for the script being taught.
