# Copyable content handoff

Open this repository and begin with AGENTS.md. For a first session use the Foundation chapter 1 prompt in README.md. Continue with chapters in book.json order, reading earlier script/vocabulary items so new/review flags stay truthful. Requested batches are allowed; do not truncate the final chapter to finish a batch.

Required response: exact relative file path, full valid JSON for each authored chapter, matching image prompts inside that JSON, brief change summary and checks actually performed. If tool access cannot write to GitHub, return files for the manager to import. Never claim a commit or push without evidence.

For later sessions: "Read the repository instructions and current book.json. Author the next requested complete chapter(s), preserving IDs and the script progression. Do not overwrite completed chapters. Run the validator if execution is available, otherwise state that it was not run."

For vocabulary sessions: "Read 04-easy-hindi-vocabulary-7000-words/book.json and rosters/README.md. Propose the next chapter's 25 Hindi words plus 5 natural expressions using the reserved IDs and category positions. Check all earlier rosters for duplicates. Give level rationale and reliable sources or explicit review flags; do not invent citations. After roster review, author the complete chapter with script practice, context sentences, two readings and image prompts."

The manager imports returned JSON, validates structure, coordinates editorial review and handles later production. Draft lessons, image prompts, actual images and published books are distinct deliverables.
